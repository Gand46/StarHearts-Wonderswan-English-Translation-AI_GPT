# Technical findings — Star Hearts 13BG-F34

This is a synthesis of the supplied F34 source and the original audit reports in `research_original_es/`. Addresses retain the original notation: `0x...` in the ROM column means **file offset**, `9000:...` or `A000:...` means a **segmented CPU address**, and `C...`, `D...`, `E...` labels in cited reports refer to emulated RAM unless expressly identified as ROM or SRAM. The relationship between a segmented address and a file offset is shown only where the report itself established both. Historical reports describe their own earlier versions; the I14-P9 ledger governs F34 acceptance.

## Structural inventory and uncertain material

The F19 baseline recorded 237 active candidates: 23 higher-confidence static and 214 `0x0022` operands. F20–F26 integrated 11 + 4 + 8 + 45 + 63 + 54 + 52 = 237 records. The F26 structural recensus had 238 dispositions including retained `Ａ型`. Bank `0x38` contained 1,568 slots across five pointer families; 1,396 original Japanese targets, 1,395 repointed plus one translated in place, and no active Japanese survivor in those audited targets. This is a **bounded inventory**, not a whole-ROM completion claim. A raw text auditor found far more candidates (7,861 strict; 43,949 including isolated characters), many of which are data, code or retained source strings. See `baseline/AUDITORIA_JAPONES_PENDIENTE_F19.md`, `iterations/I10/I10_STRUCTURAL_CLOSURE_REPORT.md`, and `PROJECT_STATE.json` in the preserved research tree.

The 181 padded fields near opcode operands are not consumed through route T01; a separate consumer has not been demonstrated, so the source leaves them intact. An early Link selector/flag study and Magic/Fire acquisition mapping are retained in `iterations/I11/I11_P4_LINK_SELECTOR_REPORT.md` through `I11_P16_MAP_AND_SHOP_SOURCE.md`; their earlier gate status should be read alongside the I14-P9 acceptance record. Exact ROM/CPU/RAM address types must not be inferred from a nearby hex value.

## F34 typography, binary constraints and evidence

The F34 banner correction avoids token `F04C` (`en`, previously mislabeled as uppercase `EN`) and token `F079` (which dropped `ir` in this special consumer). The same 28-byte slot, controls and native renderer remain. The Link formatter destination word changes `F3B2` to `F3BE`; the WonderSwan checksum is `3CD5`. F34 changes no glyph, dictionary, shared renderer, palette or synthetic warp. The P9 audit rejected blended WAITING frame 600, accepted stable frame 720 and transcribed nine isolated native glyphs; the reviewer already knew the phrase, so this is not an independent blind study. Of 94 printable Latin/symbol glyphs compared with JP, 93 match; legacy underscore differs at two bytes but visible use remains `NOT_VALIDATED`.

All address/certainty entries above come from source manifests and specific reports preserved under `research_original_es/`. The full original disassemblies and private save states are deliberately excluded; these tables preserve their key documented entry points and resource relationships without redistributing a whole game dump. Current captures and traces listed in `EVIDENCE_INDEX.csv` have individually checked SHA-256 hashes.
