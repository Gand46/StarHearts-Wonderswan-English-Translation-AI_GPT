# Historical project documentation

These records are retained as evidence for their named builds, grouped into build-specific subfolders. The current authority is the [repository README](../../README.md), [F37 technical report](../technical/TECHNICAL_F37.md) and [F37 project state](../status/PROJECT_STATE_F37.json).

The original text is preserved, including earlier unresolved items, historical wrapper targets, Spanish notes and references to working-directory paths or external audit bundles that were not part of the F37 source distribution. Those references are provenance, not current setup requirements.

In particular, the four prompt graphics listed as pending in F36 were translated and synthetically rendered in F37. F35 hardware observations are not a current F37 compatibility verdict. Current root build wrappers target F37 even when a historical report describes an earlier wrapper target.

Root-relative file paths printed in these historical reports refer to the earlier source-tree layout. The [file relocation index](../project/FILE_RELOCATION.csv) maps those locations to the organized package. Current build instructions and paths are in the repository README; historical commands must be interpreted in their recorded build context.
